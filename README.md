# QR Pelplin — pojedyncza wtyczka WordPress

Wersja 0.1.0: typ treści QR, kategorie, landing page ze shortcode, widok pojedynczej treści i podstawowy panel administracyjny. Bez Next.js.

## Instalacja
1. Spakuj folder `qr-pelplin` jako `qr-pelplin.zip`.
2. W WordPressie: Wtyczki → Dodaj nową → Wyślij wtyczkę → Aktywuj.
3. Ustawienia → Bezpośrednie odnośniki → Nazwa wpisu.
4. Wtyczka tworzy stronę „Odkrywaj Pelplin”. W Ustawienia → Czytanie ustaw ją jako statyczną stronę główną.
5. Dodawaj materiały w Treści QR; adresy mają format `/q/nazwa-wpisu/`.

## Następne etapy
Generator QR PNG/SVG, stabilne adresy i zliczanie skanów, statystyki, mapa, galerie, wyszukiwarka, edytowalny landing page, eksport i aktualizacje. Nie są jeszcze zaimplementowane.

Nie przechowuj haseł do hostingu w repozytorium.
